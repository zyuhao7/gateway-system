4. **CPU上下文切换**

   - 需求: 50K连接
   - 结论: 充足

### 压测命令

```bash
# 编译服务器
cmake --build build --target gateway_server

# 启动服务器（4线程）
./build/gateway_server 8080 4

# 压测（20K连接）

# 监控CPU

# 监控网络
sar -n DEV 1

# 监控文件描述符
lsof -p $(pgrep gateway) | wc -l
```

### 性能调优

#### 系统参数
```bash
# 增加文件描述符
ulimit -n 1048576

# TCP调优
sysctl -w net.ipv4.tcp_max_syn_backlog=8192
sysctl -w net.core.somaxconn=8192
sysctl -w net.ipv4.tcp_tw_reuse=1
```

#### 编译优化
```bash
# Release模式
cmake -DCMAKE_BUILD_TYPE=Release -B build

# LTO优化
cmake -DCMAKE_INTERPROCEDURAL_OPTIMIZATION=ON -B build
```
